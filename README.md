# Satu Molekul, Tiga Tarian — video Spektroskopi Molekul

Film edukasi **Spektroskopi Molekul** (Kimia Kuantum S1 Kimia UNESA, RPS pertemuan 14), dibuat dengan [Remotion](https://remotion.dev). ±10 menit, 17 adegan, 2K 30 FPS, subtitle kata-per-kata.

Isi: JWST & WASP-39b → empat tangga energi → spektrum sebagai penggaris → populasi Boltzmann → aturan seleksi → spektrum rotasi CO → vibrasi-rotasi HCl (P/R, isotop) → Raman → spektrum elektronik & Franck–Condon → translasi & Doppler → alat uji napas → astronomi radio CO → atmosfer exoplanet.
